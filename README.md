## 🎮 Featured Project

<div align="center">

### **Game Hub**
*A personal game tracking platform inspired by modern gaming interfaces*

[![View Project](https://img.shields.io/badge/View_Project-4CAF50?style=for-the-badge&logo=vercel&logoColor=white)](#)

</div>

**Game Hub** is more than just a game tracker — it's a companion app that brings the polish and feel of modern gaming UIs to the web.

#### ✨ Key Features
- 🎮 **RAWG API Integration** — Access a vast game database
- 📚 **Personal Library** — Track your gaming journey
- 🔐 **Supabase Auth** — Secure user authentication
- 🎨 **Multiple Layouts** — Customize your viewing experience
- 🔍 **Advanced Filtering** — Search, sort, and filter with precision
- 📱 **Fully Responsive** — Seamless across all devices
- 🎯 **Custom UI System** — Unique visual identity and design language

#### 🛠️ Built With
```
Next.js • TypeScript • Tailwind CSS • Supabase • PostgreSQL • RAWG API
```
